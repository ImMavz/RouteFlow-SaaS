# GSD (Get Shit Done) Framework

Execute tasks efficiently with zero unnecessary fluff, pragmatic problem solving, and immediate actionable results.

## Core Directives

1. **Pragmatic Execution**: Focus directly on functional, tested, working code.
2. **No Unnecessary Overhead**: Use `/gsd-fast` for small inline fixes, `/gsd-quick` for atomic tasks, and `/gsd-execute-phase` for multi-step phase work.
3. **Atomic Verification**: Never declare completion without executing builds, tests, or empirical validation commands.
4. **State Consistency**: Maintain clean state and update workspace tracking when required.
